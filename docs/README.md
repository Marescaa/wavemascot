### Update notice

When there's a new version, Wave says so once. On Windows, **Update** downloads it, checks it and installs it keeping
your settings; on Mac it opens the download page.

<img src="capturas/en/aviso-actualizacion.gif" width="250" alt="Update notice with Update and Not now buttons">
