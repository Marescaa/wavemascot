# Assets and third-party software

## Sprites, icon, flags and sounds: all original

There are no images, sounds, fonts or logos from Anthropic or anyone else in this repository.

| Asset | Origin |
|---|---|
| Mascot (every state, outfit and accessory) | Original pixel art drawn as pixel matrices in [`sprites.py`](sprites.py). The GIFs are generated on your computer the first time they're needed (`~/.wavemascot/cache`). |
| `assets/icono.ico` | Generated by `sprites.py` (`icono_bandeja`) from the same pixel art. |
| `assets/sonidos/*.wav` | Synthesized by `sprites.py` (sine waves with harmonics and an envelope); not recordings or samples. Regenerate them with `python sprites.py`. |
| `assets/ui/flecha-*.svg` | Dropdown arrows, written by hand (a single `path`). |
| Language flags | Drawn in code with simple shapes (`bandera()` in [`ajustes.py`](ajustes.py)). |
| Font | Segoe UI, the Windows system font; not included in the repository or the `.exe`. |

Attributions required by the assets: **none**. Everything is published under the project's [MIT license](LICENSE).

### What the `.exe` includes

`WaveMascot-Setup.exe` is built with [PyInstaller](https://pyinstaller.org) and includes:

| Component | License |
|---|---|
| Python | PSF License |
| PyQt6 | GPL v3 |
| Qt 6 (Core, Gui, Widgets, Network, Multimedia, Svg) and its translations | LGPL v3 |
| FFmpeg (Qt Multimedia backend) | LGPL v2.1 or later |
| Pillow | MIT-CMU (HPND) |
| OpenSSL (`libcrypto`, used by Python's `hashlib`) | Apache 2.0 |
| libffi | MIT |
| PyInstaller bootloader | GPL v2 or later, with a bootloader exception |
| Microsoft Visual C++ Runtime | Microsoft redistributable |

Because the executable includes PyQt6 (GPL v3), **the `.exe` as a whole is distributed under the terms of the GPL v3**.
The complete source code and the instructions to build it (`build.ps1`) are in this repository. The project's own code
remains MIT, which is compatible with the GPL v3. The license texts ship with the installed program, in the
`licencias` folder.
