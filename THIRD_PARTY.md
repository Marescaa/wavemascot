# Assets and third-party software

## Sprites, icon, flags and sounds: all original

There are no images, sounds, fonts or logos from Anthropic or anyone else in this repository.

| Asset | Origin |
|---|---|
| Mascot (every state, outfit and accessory) | Original pixel art drawn as pixel matrices in [`sprites.py`](sprites.py). The GIFs are generated on your computer the first time they're needed (`~/.wavemascot/cache`). |
| `assets/icono.ico`, `assets/icono.icns` | Generated by `sprites.py` (`icono_bandeja`, `icono_app`) from the same pixel art. |
| `assets/sonidos/*.wav` | Synthesized by `sprites.py` (sine waves with harmonics and an envelope); not recordings or samples. Regenerate them with `python sprites.py`. |
| `assets/ui/flecha-*.svg` | Dropdown arrows, written by hand (a single `path`). |
| Language flags | Drawn in code with simple shapes (`bandera()` in [`ajustes.py`](ajustes.py)). |
| Font | The system font: Segoe UI on Windows and San Francisco on macOS; not included in the repository, the `.exe` or the app. |

Attributions required by the assets: **none**. Everything is published under the project's [MIT license](LICENSE).

## Third-party software

The project's source code is MIT. To run from source, these are installed separately:

| Package | License | Used for |
|---|---|---|
| [PyQt6](https://www.riverbankcomputing.com/software/pyqt/) | GPL v3 | Windows, animation, sound |

On macOS, `install.sh` installs them in a virtual environment of its own; the window, focus and full-screen checks use
macOS's own frameworks (CoreGraphics, AppKit) through Python's `ctypes`, with no extra packages.
| [Pillow](https://python-pillow.github.io/) | MIT-CMU (HPND) | Generating the mascot GIFs |

### What the `.exe` and the Mac app include

`WaveMascot-Setup.exe` and `WaveMascot.app` (inside the `.dmg` files) are built with
[PyInstaller](https://pyinstaller.org) and include:

| Component | License |
|---|---|
| Python | PSF License |
| PyQt6 | GPL v3 |
| Qt 6 (Core, Gui, Widgets, Network, Multimedia, Svg) and its translations | LGPL v3 |
| FFmpeg (Qt Multimedia backend) | LGPL v2.1 or later |
| Pillow | MIT-CMU (HPND) |
| OpenSSL (`libcrypto`, used by Python's `hashlib`) | Apache 2.0 |
| libffi | MIT |
| PyInstaller bootloader | GPL v2 or later, with a bootloader exception |
| Microsoft Visual C++ Runtime (Windows only) | Microsoft redistributable |

Because they include PyQt6 (GPL v3), **the `.exe` and the Mac app as a whole are distributed under the terms of the GPL
v3**. The complete source code and the instructions to build them (`build.ps1`, `build-mac.sh`) are in this
repository. The project's own code remains MIT, which is compatible with the GPL v3. The license texts ship with the
installed program, in the `licencias` folder (on Mac, inside `WaveMascot.app/Contents/Resources`).
